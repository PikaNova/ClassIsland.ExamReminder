# 考试提醒 0.3.2.1 交付说明

适用版本：ClassIsland 2.1.0.1。

## 文件

- ClassIsland.ExamReminder-0.3.2.1.cipx：插件安装包，在 ClassIsland 插件页安装后重启。
- ClassIsland.ExamReminder-0.3.2.1-source.zip：对应源码与检查项目，不含构建缓存。
- Novora-ClassIsland-0.3.patch：配套服务器补丁，基于 Novora 958e209；包含接口、测试、说明，无数据库迁移。
- SHA256SUMS.txt：上述文件的 SHA-256 校验值。
- ui/：实际设置页的无头渲染截图。

## 0.3.2.1 新增

- 考试取消识别：同步发现原本未结束的考试整场从安排里消失时，报一条「取消 原定 MM-dd HH:mm」，与既有变更提醒共用开关、合并汇总、班级不变护栏和持久去重；已结束的场次被服务端清理不算取消，仍在安排里的考试即使时间已过也不算取消。纯本地比较，未改动看板协议。
- 限制：看板协议没有考试状态字段，插件无法区分“真实取消”与“服务端数据缺失或只返回部分安排”；需要区分时仍需服务端补 status 与 capability。
- 检查由 72 项增至 75 项，新增取消上报、已结束场次不误报、仍存在考试不误报三项。

## 0.3.2.0 既有能力

- 考试安排变更提醒：未来考试的名称、开考或结束时间变化及新增考试时合并提醒一次；首次同步、换班、缓存恢复和离线数据不触发，同一变更重启后不重复。
- 次日考试预告：按学校时区计算明天考试，在每天指定时间最多播报一次；明天没有考试时保持安静，默认关闭。
- 设置页 P1 整理：将提醒设置拆成语音、考前与开考、结束、安排变更与次日预告、提醒显示、考试模式、来源屏蔽和看板守护；高级页拆出同步、离线缓存、公告与诊断。
- “断开本机连接”改为 5 秒内二次确认，避免误触停用考试快照。

## 0.3.1.0 既有能力

- 新增结束前提醒节点（默认 15、5 分钟）和“考试结束”提醒，结束前/结束文案可分别编辑；结束时间变化后会重新计算去重键。
- 连考场次：上一场未结束或刚结束 60 秒内，不播报下一场的考前提醒；无缝衔接时上一场的结束提醒让位给下一场开考提醒。
- 同步失败或数据超过两个检查周期（至少 5 分钟）时，提醒遮罩、今日安排和运行诊断会标注“离线数据”和最后同步时间。
- 概览重构为响应式仪表盘：宽屏左侧“下一场考试”Hero 卡（大号倒计时、名称、时间/班级 chip），右侧“今日安排”时间线；下方“自动考试模式”和“设备与同步”指标网格。已连接时收起配对卡，断开操作改为危险文字按钮；窄于 760 自动堆叠，最大宽度 1120。
- 设置页移除硬编码灰色和 0.72 透明度，改用 ClassIsland/FluentAvalonia 主题资源，并为缺失资源注入浅色/深色 fallback；所有状态统一使用“圆角 chip + 文本”，按钮区分 accent 主操作、outline 次操作和危险文字操作。
- 作者公告改为扁平列表：顶部工具栏集中状态、未读数、“只看未读/刷新/全部已读”；每条公告带分隔线，置顶/未读用 chip，去掉卡片嵌套，展开正文沿用列表背景；空状态显示图标、标题和说明。
- 概览新增“今日安排”：按学校时区列出今天的考试时间、名称与状态（待开始／进行中／已结束），跨午夜和跨中午的考试也会正确归入当天。
- 同步状态区分“最近成功”“上次尝试”“数据校验/缓存时间”，并显示下次检查的倒计时；不再把失败尝试显示成最近同步。
- 作者公告增加未读统计与“只看未读”，展开阅读后保留当前文章直到刷新；失败原因改为中文（超时、网络、限流、HTTP 状态等），原始技术错误只写入运行诊断。
- 提醒来源增加“默认来源 / 全选 / 清空”和已选数量，长名称自动换行；宿主不支持屏蔽时快捷操作会提示原因。
- 语音区新增当前引擎、宿主音量状态和“测试语音引擎”按钮；直接调用宿主 TTS，不依赖考试数据，音量为 0 时明确提示。
- 移除“自定义公告地址”和“考前复查窗口”设置：公告固定跟随看板代理或作者公开源；开考前 1 分钟复查保留为内部固定行为。
- 运行诊断增加“复制诊断信息”，包含版本、同步状态、缓存、公告与屏蔽状态；不包含客户端密钥、配对令牌或恢复密钥。
- 状态提示会自动过期，保存或连接成功后不再保留上一条错误文本。

## 插件主要变化

支持内网 HTTP，宿主语音，上午/下午连续考试模式，按提供方选择屏蔽提醒。
新增考试安排变更提醒和可选次日考试预告；设置页按提醒职责分组，危险操作需要二次确认。
默认提前 15 分钟进入考试模式、13:00 分界，均可调整。自己的考试提醒始终保留，未选来源正常提醒。
设置页分为概览、提醒与考试模式、作者公告、连接与高级，支持主题与窄窗口。
同步默认 60 秒并错峰；支持版本检查、完整校验、退避、本地离线缓存；提醒计时独立运行。
作者公告独立低频获取，只在设置页显示及标记未读，不弹窗或播报。
完整设置范围参见源码根目录 README.md。

## 服务端部署

在对应 Novora 源码根目录先检查，再应用：

```powershell
git apply --check 路径/Novora-ClassIsland-0.3.patch
git apply 路径/Novora-ClassIsland-0.3.patch
```

若当前版本已改动相同代码，需按实际冲突合并；不要覆盖已有改动。
按 Novora 原部署流程构建和重新部署。补丁无需数据库迁移及新环境变量。
详细协议和检查说明见补丁中的 docs/CLASSISLAND-0.3.md。
未部署补丁时插件仍兼容旧服务端，但使用完整同步；需要配套服务端才能实现轻量版本检查。
