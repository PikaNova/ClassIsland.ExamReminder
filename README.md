# 考试提醒

连接 Novora 考试看板的 ClassIsland 插件。当前版本 **0.3.2.1**，面向 **ClassIsland 2.1.0.1**，使用提醒 V2 与宿主语音引擎。

项目主页：<https://github.com/PikaNova/ClassIsland.ExamReminder>
看板项目：<https://github.com/PikaNova/Novora>

0.3.2.2 新增“提醒类型”选择：在 ClassIsland 的“提醒 → 考试提醒 → 基本设置”中分别启用即将开始、考试开始、结束前、考试结束、考试时间变更和次日预告。提醒覆盖绑定班级的全部适用日程；自动考试模式始终按完整日程运行，不受提醒类型选择影响。
0.3.2.1 修复暂停中的考试超过原定结束时间后从概览隐藏，以及恢复后暂停延长未正确参与有效结束时间和变更检测的问题。

## 安装与连接

从 Releases 或本地构建输出取得 .cipx，在 ClassIsland 插件页安装并重启。
在“考试提醒 → 概览”填写部署地址，点击“连接并在浏览器绑定”，在浏览器中确认班级。

支持 HTTPS、内网 HTTP、主机名、端口和部署子路径，例如 http://192.168.1.20:3000。
HTTP 为明文传输；网址中不能填写用户名或密码。

更换地址、重新配对或断开本机连接时，会停用旧考试快照。断开本机连接不等于撤销服务器的设备授权。

### Novora 在线服务

插件设置中的“服务类型”可选择学校版或在线版。在线版只接受 HTTPS：点击连接后插件打开配对网页，登录 Novora 在线账号并选择一场已发布的考试；授权确认后插件开始同步考试。重新配对确认前，当前已连接考试保持可用。在线版通过 `/api/online` 使用独立协议，不读取学校、班级或看板在线状态；学校版 API 与本地缓存范围保持原样。

在线版使用服务端返回的发布快照和时区，通过 HTTPS 定期检查版本并同步变更。WSS 实时通知不是当前插件连接的前置条件。撤销设备、授权到期或考试归档后，插件会停止使用该授权及其缓存；短暂网络故障则按离线缓存设置处理。实际配对仍需服务端部署配对 API 和网页，并在公网环境联调验收。

## 设置页

- **概览**：仪表盘式布局。宽屏为两列：左侧“下一场考试”Hero 卡显示大号倒计时、考试名称、时间与班级 chip；右侧“今日安排”时间线列出场次、时段和状态。下方“自动考试模式”与“设备与同步”以指标网格展示提前进入、延后退出、上下午分界、屏蔽来源、连接、看板数据、下次检查和最近成功。已连接时收起配对卡，断开操作移入设备卡。
- **提醒与考试模式**：提醒类型在宿主“提醒 → 考试提醒 → 基本设置”中管理；本页配置语音、考前与结束节点、安排变更与次日预告文案、提醒显示、考试模式、来源屏蔽和看板守护。
- **作者公告**：顶部工具栏显示状态、未读数及“只看未读/刷新/全部已读”；每条公告为带分隔线的扁平行，置顶与未读使用圆角 chip，展开正文沿用列表背景，不做卡片嵌套；空状态显示图标、标题和说明。不弹窗、不朗读。
- **连接与高级**：自动同步、请求与缓存参数、公告检查周期、运行诊断与一键复制。

所有状态统一为“圆角 chip + 文本”，颜色绑定 ClassIsland/FluentAvalonia 主题资源，缺失时注入浅色/深色 fallback，不再硬编码灰色或透明度。按钮区分 accent 主操作、outline 次操作与危险文字操作。内容最大宽度 1120，宽屏两列；窄于 760 时自动堆叠。使用宿主控件，支持浅色/深色主题及窄窗口。开关和数字自动保存，文字设置在离开输入框时校验保存。

“测试语音引擎”直接调用 ClassIsland 当前语音服务，不依赖考试数据，并显示引擎名称与宿主音量。系统 TTS 使用 Windows 已安装语音；Edge TTS 需要联网。听不到时先检查宿主语音音量、Windows 输出设备和系统语音包。

| 自动打开看板 | 开启，提前 20 分钟 | 可关闭；提前量 1–240 分钟 |
| 考试中守护 | 开启 | 检查频率跟随同步间隔 |
| 连续离线确认 | 2 次 | 1–10 次；网络失败是未知，不作为离线确认 |
| 重开最短间隔 | 120 秒 | 30–3600 秒，连续失败会延长 |
| 重开退避上限 | 15 分钟 | 1–120 分钟，不低于最短间隔 |
| 作者公告 | 开启，30 分钟 | 可关闭；周期 5–1440 分钟，失败继续退避 |

默认进入考试模式前不会改动课表。一天分上午、下午，各段从首场考试（含提前量）持续到最后一场结束（含延后量），场间保持；跨中午考试全程覆盖，重叠区间合并。

连考时，上一场尚未结束或刚结束的 60 秒内，不会播报下一场的考前提醒，避免打断当前考试；下一场的开考提醒仍保留。若两场几乎无缝衔接，上一场的“考试结束”提醒会让位给下一场的开考提醒。

同步发现未来考试的名称、开考或结束时间变化、新增未来考试，以及原本未结束的考试从安排里消失（取消）时，会合并提醒一次；同一变更重启后不重复。首次快照、班级切换、缓存恢复和离线数据不触发变更提醒。已考完的场次被服务端清理不算取消；只有班级绑定不变时才做比较，因此换班不会把整份旧安排误报成取消。取消是本地推断：看板协议没有考试状态字段，插件无法区分“真的取消”和“服务端数据缺失”，超过 3 处变更会汇总成一条提醒。次日预告按学校时区计算“明天”，默认关闭，可在每天指定时间播报考试数量和首末场。

提醒屏蔽按**提供方整组**控制，上下课包含准备上课、上课、下课/课间休息。未选择的来源保留，地震等紧急提醒默认不屏蔽。本插件自己的考试提醒不能被屏蔽。设置页提供默认、全选、清空快捷操作，并显示已选来源数量。

ClassIsland 2.1.0.1 没有公开的通用筛选事件，因此使用宿主自带 Harmony 的运行时适配，拦截选中来源，并在进入模式时取消这些来源已有的排队/播放任务。不会修改宿主提醒配置，退出即恢复；适配不兼容时停用屏蔽并显示原因，不关闭全局提醒。

## 同步与离线

网络同步与本地提醒独立。网络超时不会暂停本地考试倒计时。使用服务端时间与请求耗时校正，并在两次同步间用单调时钟推进。概览区分最近成功同步、上次尝试和缓存时间，并显示下次检查倒计时。同步失败或数据超过两个检查周期（至少 5 分钟）时，提醒遮罩、今日安排和诊断会标注“离线数据”及最后同步时间。

支持条件同步的 Novora：
- POST /api/exams，action=plugin-bootstrap，带 knownVersion 和 includeCompletedToday=true。
- 无变化只返回版本、时间和在线状态，不重复传考试列表。
- 完整数据保留当天已结束考试，避免场间重新计算丢失上午/下午的起点。
- 开考前 1 分钟自动复查一次，尽量捕获临时调整。
- 默认约一分钟获知考试变更；断网或限流期间会延迟。

旧看板会忽略新请求字段，插件自动兼容为每分钟完整同步。已见过的当天结束考试会在本地保留，但首次在场间启动的旧服务端可能无法提供完整时段，建议安装配套的 Novora 更新。

考试缓存按服务器、设备凭据和班级隔离；已知绑定失效立即停用。缓存超时或用户关闭离线缓存后，不再依据旧数据触发提醒/自动打开/考试模式。提醒去重在本地持久化，并迁移 0.2.6 的动作记录。运行诊断中的“复制诊断信息”可用于反馈问题，不包含客户端密钥或配对令牌。

## 作者公告

默认复用看板 /api/announcements；未配置看板时使用作者公开公告源，公告地址不再单独配置。
独立获取、延迟启动、本地缓存，公告故障不影响考试。公告按 ID 与更新时间记录已读，更新后重新未读；有效空列表会清除已撤下内容。到期公告即使离线也会隐藏。图片随正文展开加载。
设置页显示未读数量、最近成功时间和上次尝试时间，支持只看未读；网络失败时保留缓存并显示中文原因，原始技术错误只写入运行诊断。

公告只提供内容与链接，不修改插件设置或执行公告中的指令。

## 构建

安装 .NET 8 或更新 SDK：

~~~powershell
dotnet build -c Release -p:CreateCipx=true -p:PowershellBinaryName=powershell
~~~

输出：cipx/ClassIsland.ExamReminder.cipx。PowerShell 7/Linux 可将 PowershellBinaryName 改为 pwsh。

## 验证

检查项目需 .NET 10（匹配当前 Windows 2.1.0.1 宿主依赖），并传入含 ClassIsland.dll 的应用版本目录：

~~~powershell
dotnet run --project tests/ExamReminder.Checks.csproj -c Release -- "你的ClassIsland应用版本目录"
~~~

独立检查覆盖网址校验、提醒类型、考试分段、今日安排、考前/结束提醒边界、连考避让、考试安排变更与取消、次日预告、离线数据标记、去重存储、HTTP 条件同步、断网缓存、公告失败本地化及界面渲染。当前 standalone 检查 46 项通过；传入宿主应用目录后还会运行宿主程序集提醒拦截/恢复及集成检查。截图输出到 outputs/ui，包含提醒类型提供方设置、概览和作者公告。

这些检查不启动或改动已安装的 ClassIsland，不验证扬声器实际声音、浏览器真实打开和第三方提醒插件的全部行为。安装后应使用设置页“测试语音引擎”直接检查宿主当前 TTS，再用“测试考试提醒”验证完整通知链路。
